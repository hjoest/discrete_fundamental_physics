1. **A locally finite causal poset $(P, \le_P)$** representing discrete spacetime events and causal precedence,

   $$\exists\, \sigma \in S_m,\, \tau \in S_n : \quad \prod_{i=1}^m \pi_G(u_{\sigma(i)}) = \prod_{j=1}^n \pi_G(v_{\tau(j)})$$
